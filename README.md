# An Automated Method to Correct Artifacts in Neural Text-to-Speech Models — audio samples

Demo page: https://seongyeop-jeong-poey.github.io/interpretable-tts/

**Paper**: Seongyeop Jeong, June Sig Sung, Inchul Hwang, Jaesik Choi.
*An Automated Method to Correct Artifacts in Neural Text-to-Speech Models.*
IEEE/ACM Transactions on Audio, Speech, and Language Processing, 2025.
DOI: [10.1109/TASLPRO.2025.3550718](https://doi.org/10.1109/TASLPRO.2025.3550718)

The method detects and corrects artifact-inducing internal units of a neural TTS model without manual error
specification, model retraining or additional data. This repository hosts the listening samples
(original vs. corrected speech) shown on the demo page.

Author homepage: https://seongyeop-jeong-poey.github.io
